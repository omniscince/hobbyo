# 1. Карточка проекта Hobbyo

| Поле | Содержание |
|---|---|
| **Тема проекта** | Hobbyo — сервис подбора хобби и записи на пробные занятия с учётом личного графика пользователя |
| **Категория системы** | Веб-приложение (адаптивное, mobile-first) с последующим выпуском мобильного приложения |
| **Заказчик** | Стартап-команда FIP 13 (TSI AUCA, программа SEST), г. Бишкек |
| **Настоящая ситуация** | |
| **Деятельность, которую хочется улучшить** | Поиск нового хобби жителями Бишкека и запись на занятия в студии, секции и клубы |
| **Заинтересованные стороны** | 1. Заказчик (команда FIP 13)<br>2. Пользователи 14–45 лет, ищущие новые занятия<br>3. Родители, подбирающие секции для детей<br>4. Организации: студии, мастерские, секции, клубы, организаторы мероприятий<br>5. Платёжные системы КР (MBank, Элсом, O!Деньги)<br>6. Научный руководитель курса ФМП |
| **Текущее решение**<br>(как сейчас работают люди) | Пользователь:<br>1) Случайно видит занятие в ленте Instagram / TikTok или узнаёт от знакомых (время не контролируется)<br>2) Ищет страницу организации в Instagram или 2ГИС (5–15 мин)<br>3) Пишет в WhatsApp или звонит, уточняет цену и расписание (от 10 мин до 1 дня ожидания ответа)<br>4) Сверяет расписание со своим графиком вручную<br>5) Приходит на пробное занятие<br><br>Организация:<br>1) Публикует рекламу в Instagram и родительских WhatsApp-чатах<br>2) Администратор или сам тренер отвечает на сообщения и звонки<br>3) Вручную ведёт запись и напоминает клиентам |
| **Существующие проблемы**<br>(что плохого происходит, как часто, в чём измеряется) | Пользователи (по CustDev, 20 респондентов):<br>- 60% хотят «сходить пару раз попробовать», но не знают, куда и как<br>- Пользователь знает, что ему не нравится, но не знает, что понравится, пока не попробует<br>- Главные барьеры: лень, нехватка мотивации и несовпадение с графиком<br>- Страшно идти одному на новое занятие<br>- Родителям сложно совмещать секции нескольких детей со школой и садиком<br>- Не нравится покупать долгий абонемент ради одного пробного занятия<br><br>Организации (интервью: «Арт Вилль», Flip_dance, страйкбол-полигон):<br>- Клиенты приходят в основном по сарафанному радио и через WhatsApp-чаты, других каналов нет<br>- Запись, ответы и подтверждения ведутся вручную |
| **Целевая ситуация** | |
| **Цель для заказчика**<br>(что получит бизнес после реализации проекта?) | - Подключить не менее 15 организаций Бишкека в течение 3 месяцев после запуска<br>- Привлечь не менее 500 зарегистрированных пользователей за первые 3 месяца<br>- Достичь конверсии «пробное занятие → регулярные занятия» не ниже 20%<br>- Получать доход с комиссии за записи и платного продвижения организаций |
| **Назначение**<br>(цель для пользователя) | Для пользователя:<br>1. Найти подходящее хобби за 1–3 пробных занятия без покупки абонемента<br>2. Записаться на занятие в своё свободное время не более чем за 3 минуты<br><br>Для организации:<br>1. Получать новых клиентов без ручной переписки<br>2. Сократить время на запись, подтверждения и напоминания |
| **Системы-аналоги** | ClassPass (пакеты занятий в разных студиях), DIKIDI (онлайн-запись), Pinterest (персонализация по анкете при регистрации), Duolingo (механики удержания мотивации) |
| **Системы-конкуренты** | ticket.kg (афиша мероприятий), 2ГИС (каталог организаций), Bishkek Events, Instagram-страницы студий, Shodim |
| **Концепция решения** | |
| **Количество видов пользователей (ролей)** | 1. Гость<br>2. Пользователь<br>3. Организация<br>4. Администратор |
| **Ключевые свойства и возможности (3–10 фич)** | 1. Анкета интересов при регистрации (7 вопросов) и персональные рекомендации с % совпадения<br>2. Личный график: свободные окна пользователя в неделе<br>3. Подбор слотов пробных занятий, которые попадают в свободные окна<br>4. Запись на пробное занятие без абонемента, оплата за одно посещение<br>5. Бандлы хобби: подборки направлений одной тематики<br>6. Поиск организаций на карте рядом с домом, учёбой или работой<br>7. Кабинет организации: профиль, занятия, расписание, список записавшихся<br>8. Платное продвижение организаций и подписка Pro (после финмодели) |
| **Смежные системы (интеграции)** | 1. SMS-шлюз (подтверждение номера телефона)<br>2. Почтовый сервер SMTP (напоминания и уведомления)<br>3. Платёжная система (MBank, Элсом, O!Деньги)<br>4. Картографический сервис 2ГИС API<br>5. Google Calendar (экспорт записей) |
| **Необходимые отчёты** | В текущую версию отчёты не входят (приоритет Won't в ТЗ). Кандидаты на следующие версии: отчёт организации о записях и конверсии «пробное → регулярное», отчёт платформы о популярных хобби и выручке |
