# Hobbyo

**Hobbyo** — сервис подбора хобби и записи на пробные занятия с учётом личного графика. Пользователь проходит короткую анкету, получает персональные рекомендации и бандлы хобби, записывается на пробное занятие в своё свободное окно и оплачивает только посещение. Организации (студии, секции, клубы) получают новых клиентов и ведут запись без ручной переписки в WhatsApp и Instagram.

Рынок: Кыргызстан, старт — Бишкек.

Команда FIP 13 · программа SEST (Software Engineering and Social Transformation), TSI AUCA · курс ФМП.

java -jar plantuml.jar -charset UTF-8 -tpng diagrams/*.puml

## Роли

- **Гость** — смотрит каталог, бандлы и мероприятия
- **Пользователь** — анкета, рекомендации, личный график, запись на пробные занятия
- **Организация** — профиль, занятия, расписание, список записавшихся
- **Администратор** — каталог хобби и бандлы

## Планируемый стек

Python 3.12 · Django 5 · PostgreSQL 16 · адаптивный веб-интерфейс (mobile-first)
